# wass.at

Gemeinsame professionelle Dachwebsite für Dr. Romana Elisabeth Wass, PhD und Clemens Wass.

## Grundsätze
- Keine medizinische Beratung oder klinische Kontaktaufnahme über die Website
- Kein KI-Chat, kein Tracking, keine nicht erforderlichen Cookies
- Berufliche Profile sind klar getrennt
- OpenLaws bleibt eigenständige Fachplattform

## Lokal starten
```bash
npm install
npm run dev
```

## Produktion
```bash
npm run build
```

Vor Veröffentlichung sind Impressum, Datenschutz, institutionelle Angaben, Berufsbezeichnungen und Kontaktwege rechtlich und inhaltlich zu prüfen.
